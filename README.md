# Mythic-Laboratory

A collection of free resources, systems, and assets created for Minecraft server development.

This repository contains a variety of work ranging from gameplay systems and AI to custom 3D models, animations, and other Minecraft content.

## Skills & Technologies

- **MythicMobs** — Custom mobs, bosses, skills, abilities, AI behaviors, and combat encounters.
- **Java** — Gameplay systems, custom logic, and experimentation with Minecraft-related development.
- **Minecraft Datapacks** — Custom gameplay mechanics, AI behaviors, and vanilla Minecraft systems.
- **Blockbench** — Custom 3D modeling, rigging, and animation for Minecraft.
- **Minecraft Server Development** — Custom content, gameplay systems, encounters, progression, NPCs, shops, items, and events.
- **Game Design** — Encounter design, combat balancing, dungeon design, progression, and player experiences.
